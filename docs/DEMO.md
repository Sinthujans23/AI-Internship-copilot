1. Sign in and explain owner-scoped data/private storage.
2. Upload the demo PDF, inspect extracted text and the CV review category explanations. Identify rules versus AI assessment and its timestamp.
3. Find jobs: explain relevance, required versus preferred gaps, unknown salary/location and source limitations. Save one job.
4. Research an official company vacancy: open citations and distinguish vacancy evidence from general company technologies. State if the report is cached.
5. Show a public GitHub repository; distinguish detected technology from proven personal proficiency.
6. Create/open a learning roadmap. Mark one task in progress and attach a demo evidence link without claiming mastery.
7. Move the saved application with drag/drop and keyboard stage controls, add dates/notes and open history.
8. Tailor the CV: review before/after, accept one supported suggestion, preview in the existing editor and save a new version. Download both versions to show original preservation.
9. Open Career readiness: explain measured counts, saved AI assessments, stale data labels and absent mock-interview scores.
10. Show tests/audit results and the deployment/rollback plan. Never claim production deployment, real-world ranking accuracy or live AI success unless actually demonstrated.

No email or application is sent. Keep an offline screenshot/demo recording only with synthetic data if the presentation environment lacks working provider access.
