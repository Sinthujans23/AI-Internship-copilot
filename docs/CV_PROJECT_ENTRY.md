## AI Internship Copilot

**AI Application Developer | LLMs, RAG, Semantic Search, Next.js, Python**

- Built a full-stack career workspace that analyzes CVs, discovers internships, ranks jobs against candidate skills and preferences, and tracks applications and learning progress.
- Implemented hybrid job recommendations combining deterministic skill/preference scoring with semantic embeddings, plus per-job explanations and missing-skill insights.
- Developed AI-assisted CV review and conservative tailoring workflows with schema-validated outputs, evidence checks, PDF versioning, and human review controls.
- Built company research using website evidence, citation-aware retrieval augmented generation (RAG), and `pgvector`; added GitHub repository analysis for evidence-backed skill suggestions.
- Designed authenticated APIs and owner-scoped data access with Supabase Auth, PostgreSQL row-level security (RLS), private CV storage, request validation, rate limits, and bounded AI tool calls.
